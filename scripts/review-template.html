The Viewing

Clicking a listing does not navigate — it enters. The card's photograph expands from its own position to fill the screen and settles as the detail page's hero, while the route swaps underneath. The overlay only lets go once the destination has actually painted, so there is no flash between the two pages.

What is real and what is not

Images

Every image on this page is placeholder art, not photography. They are generated gradient dusk-scapes, built to read as intentional colour studies rather than to imitate houses. I did generate eight real architectural photographs and wired a build step that swaps them in, but this container's network blocks that CDN — so what you are looking at is the fallback. On a normal host the photographs would land instead.

Words

The agent, the six houses, the prices, the client quotes, the licence number and the office address are all invented. The copy is written to real standards — active voice, specific, no filler — but it is placeholder and must be replaced before this is public.

A trade I made

The client quotes were set in Fraunces italic. That one font file was 81KB on the critical path, so the quotes are now roman and the shipped display font contains no italic at all. If you want the italic back it is a real change, not a CSS tweak — the font has to be re-subset and LCP re-checked.

Still needs a person

The concept, real photography, real copy, and the brand itself. This build gets the craft floor high enough that a concept has somewhere to land — it does not supply the concept.

If you want changes

Where the levers are

  • Identity — src/data/site.ts and the palette block at the top of src/app/globals.css. Nothing else hardcodes the brand.
  • Listings and quotes — src/data/properties.ts and src/data/reviews.ts.
  • Motion feel — src/lib/motion.config.ts holds the one easing curve and the duration scale for the whole site.
  • Photography — drop real files into public/images under the existing names. Nothing else changes.
